HOW TO PREVIEW
1. Extract the ZIP file.
2. Open a terminal in the extracted folder.
3. Run: python -m http.server 8000
4. Open: http://localhost:8000
5. Select Projects > AI Workflow > SalesFlow AI.

DEMO SCOPE / IMPORTANT
SalesFlow is a front-end demonstration with fictional sample records. Adding an inquiry, assigning an owner, marking follow-ups complete and creating proposal requests work locally in the demo UI. It does not persist to a server and does not connect to Bug Hunters' real systems.
