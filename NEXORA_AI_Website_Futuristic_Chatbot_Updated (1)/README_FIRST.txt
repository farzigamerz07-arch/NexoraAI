===================================

WHAT'S INCLUDED
- 8 full pages: Home, AI Solutions, Services, Industries, About, Partners, Insights, Contact
- Shared responsive navigation and large white mega-dropdowns
- Dark futuristic hero + clean white corporate sections + dark feature sections
- Custom AI neural-chip visual (WebP) with CSS-powered 3D floating, orbital and holographic motion
- White multi-column mega menus with technical descriptions; About, Partners and Industries navigation order
- Technical AI architecture section covering model orchestration, RAG/data layer, integrations and governance
- A video-free, CSS-rendered animated hero atmosphere with orbital energy rings, particles and a floating neural processor

- Contact form with configurable mailto fallback
- SEO titles/descriptions, sitemap.xml and robots.txt

RUN LOCALLY
1. Extract the ZIP without changing the folder structure.
2. Open this folder in Visual Studio Code.
3. Install the Live Server extension.
4. Right-click index.html > Open with Live Server.

BEFORE GOING LIVE
1. Open js/config.js and replace the demo email, phone, location and social links.
2. Connect the contact form to a real form backend / CRM. The included mailto option opens the visitor's email app; it does not silently send or store submissions.
3. Replace the image placeholders by adding your images to assets/ and updating the CSS background-image locations marked in styles.css.
4. The included assets/ai-neural-chip.webp is the custom glowing neural-processor visual. It is animated with layered CSS perspective, floating motion, orbital rings, pulsing light and holographic information labels. Replace it with your own optimized visual if desired (keep the same filename).
5. Replace sample project/case-study content with real work. Do not publish invented client names, testimonials or results.
6. Review service descriptions, privacy policy, terms, business address, legal entity and all contact details.
7. Add your favicon and final logo if you have a custom brand asset.

VIDEO
The homepage does not use a background video. Its animated 3D-inspired atmosphere is built with CSS, while the neural-processor visual uses assets/ai-neural-chip.webp. This keeps the page lighter and avoids autoplay or video-loading issues.

TECHNOLOGY
HTML5 + CSS3 + vanilla JavaScript. No build tools or framework required.
Google Fonts are loaded online; local fallback fonts are provided.
